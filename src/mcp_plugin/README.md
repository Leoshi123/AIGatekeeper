# AG-Wrapper MCP Plugin

Plugin MCP para herramientas de seguridad de AI Agents.

## Instalación

El plugin vive dentro del proyecto `AIGatekeeper`. Para usarlo en otro proyecto:

```bash
# Opción 1: Copiar el módulo
cp -r src/mcp_plugin /tu/proyecto/

# Opción 2: Instalar como package (futuro)
pip install ag-wrapper-mcp
```

## Uso Básico

### Como Plugin MCP

```python
from mcp.server.fastmcp import FastMCP
from src.mcp_plugin import AGWrapperPlugin

# Crear servidor MCP
mcp = FastMCP(name="MiServidor")

# Registrar el plugin
plugin = AGWrapperPlugin(prefix="ag")  # Las herramientas se llamarán: ag_sanitize_code, ag_scan_code, etc.
plugin.register(mcp)

# Iniciar servidor
mcp.run()
```

### Como Funciones Directas

```python
from src.mcp_plugin import sanitize_code, scan_code, clean_code

# Sanitizar código
result = sanitize_code("// Generated by AI\ndef hello(): pass")

# Escanear en busca de vulnerabilidades
result = scan_code("result = eval(user_input)", language="python")

# Limpieza rápida
clean = clean_code("# AI-generated code\ndef foo(): pass")
```

## Herramientas Disponibles

| Herramienta | Descripción | Timeout |
|-------------|-------------|---------|
| `sanitize_code` | Remueve metadata de IA, secrets, paths absolutos | 30s |
| `scan_code` | Detecta patrones vulnerables (eval, exec, SQL injection, XSS, etc.) | 60s |
| `scan_directory` | Escanea todos los archivos en un directorio | 120s |
| `prune_context` | Extrae contexto mínimo relevante vía AST | 30s |
| `clean_code` | Limpieza rápida de metadata de IA | 10s |

## Recursos

El plugin registra estos recursos:

- `{prefix}://version` — Versión del plugin
- `{prefix}://languages` — Lenguajes soportados y cantidad de patrones
- `{prefix}://severity-levels` — Niveles de severidad del scanner

## Prompts

El plugin registra estos prompts:

- `security_review(code, language)` — Genera prompt para security review
- `prepare_for_ai(code, task)` — Genera prompt para procesamiento por AI

## Ejemplo: Servidor HTTP

```python
from mcp.server.fastmcp import FastMCP
from src.mcp_plugin import AGWrapperPlugin

mcp = FastMCP(
    name="AG-Wrapper",
    host="127.0.0.1",
    port=8765,
    streamable_http_path="/mcp",
)

plugin = AGWrapperPlugin(prefix="")
plugin.register(mcp)

if __name__ == "__main__":
    mcp.run(transport="streamable-http")
```

## Ejemplo: Servidor stdio

```python
from mcp.server.fastmcp import FastMCP
from src.mcp_plugin import AGWrapperPlugin

mcp = FastMCP(name="AG-Wrapper")
plugin = AGWrapperPlugin(prefix="")
plugin.register(mcp)

if __name__ == "__main__":
    mcp.run(transport="stdio")
```

## Configuración para Claude Code

Agregar en `.claude/settings.json`:

```json
{
  "mcpServers": {
    "ag-wrapper": {
      "command": "python",
      "args": ["-m", "src.mcp_server", "http"],
      "url": "http://127.0.0.1:8765/mcp"
    }
  }
}
```

```
├── core.py          # AGWrapperPlugin class + decorators
├── tools.py         # Funciones standalone (sin decorators MCP)
└── README.md        # Esta documentación
```

## Diferencias con Engram

| Característica | Engram | AG-Wrapper MCP |
|----------------|--------|----------------|
| Propósito | Memoria persistente | Seguridad de código |
| Herramientas | mem_save, mem_search, etc. | sanitize_code, scan_code, etc. |
| Estado | Stateless | Stateless |
| Backend | SQLite/JSON | N/A |

## Seguridad

El plugin incluye:
- **Timeout handler**: Cada herramienta tiene un timeout máximo
- **Error boundary**: Los errores no crashean el servidor
- **Thread pool**: Ejecución aislada por herramienta
